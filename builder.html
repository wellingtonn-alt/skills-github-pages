Paste a plain list of events, one per line, as date | event | note. This page checks it, shows you a preview, and gives you a finished file to drop into the site's sets folder. You never need to write or edit JSON by hand.

Set details

Format: date | event text | note (optional). Dates can be YYYY, YYYY-MM, or YYYY-MM-DD. Blank lines and lines starting with # are ignored. The first event you list becomes the free starting anchor.
